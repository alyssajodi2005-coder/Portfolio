01

The overview

A little context.

Our Neighborhood Mission connects families, children, and individuals of all abilities with resources, support, advocacy, and inclusive community programs. I independently designed and built its website using HTML, CSS, and Bootstrap.

Explore the live website
02

The challenge

The problem worth solving.

The website needed to present community resources and organizational information in a welcoming, accessible format. The design opportunity was to connect a community-centered mission with a clear digital experience.

Design goals & considerations

  1. Present the organization and its resources with an understandable page structure.
  2. Make navigation welcoming across screen sizes.
  3. Translate visual ideas into a working frontend using HTML, CSS, and Bootstrap.

02 · Design for different screens

The implementation uses HTML, CSS, and Bootstrap for page structure, styling, navigation, and responsive layouts. The live homepage uses a green community-support hero, three introductory resource cards, and a community highlights carousel. The captures below show the actual desktop and mobile page.

03 · Build the frontend

I independently built the website from scratch, combining custom markup and styles with Bootstrap. This work demonstrates hands-on frontend implementation alongside visual design.

Hi, I’m Alyssa.

A design mind. An engineering heart.

As Sankofa subsite lead on the Melanate project, I created wireframes and page layouts, organized content for CMS integration, and iterated with designers, developers, and the nonprofit client. For Our Neighborhood Mission, I independently built a responsive website in HTML, CSS, and Bootstrap.
